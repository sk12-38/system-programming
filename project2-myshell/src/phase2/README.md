# myshell - Phase 2

이 프로젝트의 **Phase 2**에서는 파이프라인 명령어(`|`) 처리를 중심으로, 여러 개의 명령을 연결하여 실행하는 기능을 구현합니다.

## 📌 핵심 기능 (Phase 2)
- 여러 개의 명령어를 파이프(`|`)로 연결하여 실행
- 각 명령어는 자식 프로세스로 분기하여 실행됨 (`fork`)
- `dup2`와 `pipe`를 활용한 표준 입력/출력 리다이렉션
- 앞 단계 출력 → 다음 단계 입력으로 전달되는 파이프라인 구조
- 기존 Phase 1의 기능 (`cd`, `quit`, 백그라운드 실행 등) 유지

---

## 🔧 컴파일 방법

Makefile이 제공되므로 다음 명령어로 빌드합니다:

```bash
make
```

생성된 실행 파일 이름은 `myshell`입니다.

> ⚠️ 의존 파일: `myshell.c`, `csapp.c`, `csapp.h`

---

## ▶️ 실행 방법

```bash
./myshell
```

쉘 프롬프트는 아래와 같이 나타납니다:

```
CSE4100-SP-P2>
```

---

## 💻 사용 예시

```bash
CSE4100-SP-P2> ls | grep txt
CSE4100-SP-P2> ps aux | grep bash | wc -l
CSE4100-SP-P2> echo hello | cat | cat | cat
CSE4100-SP-P2> sleep 10 & 
[3271] sleep 10 &
```

- `|` 연산자는 여러 명령어를 연결하여 **파이프라인 형태로 실행**합니다.
- 백그라운드 실행도 여전히 지원되며, PID와 함께 명령이 출력됩니다.
- 각 명령은 `execve()`를 통해 `/bin/` 디렉터리 기준으로 실행됩니다.
- `cd`, `quit` 명령은 여전히 쉘 내부에서 직접 처리됩니다.
