# System Programming Projects

## 한국어

김영재 교수님의 시스템프로그래밍 과제들을 정리한 저장소입니다. 각 프로젝트는 과제별로 분리되어 있으며, 소스 코드, 테스트 자료, 문서, 원본 참고 자료를 구분해 관리합니다.

### 프로젝트 구성

| 프로젝트 | 주제 | 폴더 |
| --- | --- | --- |
| Project 1 | MyLib | `project1-mylib/` |
| Project 2 | MyShell | `project2-myshell/` |
| Project 3 | Concurrent Stock Server | `project3-concurrent-stock-server/` |
| Project 4 | Mallocator | `project4-mallocator/` |

### 폴더 기준

- `src/`: 직접 작성하거나 수정한 소스 코드
- `tests/`: 테스트 입력, 테스트 스크립트, 기대 출력
- `docs/`: 보고서, 실행 결과, 설계 메모
- `original/`: 과제 배포 원본이 필요한 경우에만 보관

## English

This repository organizes the assignments from Professor Youngjae Kim's System Programming course. Each project is separated by assignment and structured to keep source code, test materials, documents, and original reference files easy to navigate.

### Projects

| Project | Topic | Folder |
| --- | --- | --- |
| Project 1 | MyLib | `project1-mylib/` |
| Project 2 | MyShell | `project2-myshell/` |
| Project 3 | Concurrent Stock Server | `project3-concurrent-stock-server/` |
| Project 4 | Mallocator | `project4-mallocator/` |

### Folder Guide

- `src/`: Source code written or modified for the assignment
- `tests/`: Test inputs, test scripts, and expected outputs
- `docs/`: Reports, execution results, and design notes
- `original/`: Original assignment materials, only when needed for reference
